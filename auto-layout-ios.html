01

Основи Auto Layout

Що таке Auto Layout

Система правил (constraints) яка описує розмір і позицію view відносно інших view або батьківського контейнера. Дозволяє адаптуватись до різних розмірів екрану.

Як договір між view: "я завжди буду на 16pt від лівого краю батька і по центру по вертикалі"
Мінімум constraints для view ❓ питають

Кожне view потребує повністю визначеного положення і розміру. Зазвичай потрібно 4 constraint або менше якщо view має intrinsic size.

X-позиція (leading/trailing/centerX) Y-позиція (top/bottom/centerY) ширина (width або leading+trailing) висота (height або top+bottom)
UILabel, UIButton, UIImageView мають intrinsicContentSize — ширина і висота визначаються автоматично з контенту
02

Constraints у коді

translatesAutoresizingMaskIntoConstraints = false ❓ обов'язково питають

Якщо створюєш view у коді — обов'язково виставити в false. Інакше AutoLayout конфліктуватиме зі старою системою frame-based layout.

let button = UIButton()
button.translatesAutoresizingMaskIntoConstraints = false  // ❗ не забути
view.addSubview(button)

NSLayoutConstraint.activate([
    button.centerXAnchor.constraint(equalTo: view.centerXAnchor),
    button.centerYAnchor.constraint(equalTo: view.centerYAnchor),
    button.widthAnchor.constraint(equalToConstant: 200),
    button.heightAnchor.constraint(equalToConstant: 44)
])
Динамічні constraints — змінювати через constant
var topConstraint: NSLayoutConstraint!

topConstraint = label.topAnchor.constraint(equalTo: view.topAnchor, constant: 20)
topConstraint.isActive = true

// Пізніше — змінити позицію
topConstraint.constant = 100
UIView.animate(withDuration: 0.3) { self.view.layoutIfNeeded() }
layoutIfNeeded() всередині animate — щоб constraint анімувався плавно
03

UIStackView

Навіщо UIStackView ❓ питають

Автоматично розставляє дочірні view в ряд або колонку. Не потрібно вручну прописувати constraints між елементами — StackView робить це сам.

let stack = UIStackView(arrangedSubviews: [label, button, imageView])
stack.axis = .vertical
stack.spacing = 12
stack.alignment = .center    // .fill .leading .trailing
stack.distribution = .fill   // .fillEqually .equalSpacing
StackView — як FlexBox у вебі: сам рахує відстані між елементами
alignment

Як елементи вирівнюються поперек осі.

.fill — розтягнути .center — по центру .leading/.trailing
distribution

Як елементи розподіляються вздовж осі.

.fill — перший тягнеться .fillEqually — рівні частки .equalSpacing — рівні відступи
04

Content Hugging & Compression Resistance

Content Hugging Priority ❓ часто питають

Наскільки view опирається збільшенню понад свій intrinsic size. Вищий пріоритет = view не хоче рости.

Два Label в горизонтальному StackView — хто з них розтягнеться? Той у кого нижчий hugging priority.
// Хочемо щоб titleLabel тягнувся, а badge — ні
titleLabel.setContentHuggingPriority(.defaultLow, for: .horizontal)
badgeLabel.setContentHuggingPriority(.defaultHigh, for: .horizontal)
Compression Resistance Priority

Наскільки view опирається стисненню нижче свого intrinsic size. Вищий пріоритет = view не хоче стискатись.

Якщо місця мало — який label обрізається першим? Той у кого нижчий compression resistance.
// Важливий текст не обрізається
importantLabel.setContentCompressionResistancePriority(.required, for: .horizontal)
05

Safe Area & Layout Margins

safeAreaLayoutGuide ❓ питають

Зона екрану яка не перекрита нотчем, home indicator або status bar. Контент треба прив'язувати до safeAreaLayoutGuide а не до країв view.

button.bottomAnchor.constraint(
    equalTo: view.safeAreaLayoutGuide.bottomAnchor,
    constant: -16
).isActive = true
Кнопка "Далі" внизу — завжди над home indicator, не під ним
layoutMarginsGuide

Системні відступи від країв (зазвичай 16pt з боків). Зручно для стандартного відступу контенту без хардкоду.

label.leadingAnchor.constraint(
    equalTo: view.layoutMarginsGuide.leadingAnchor
).isActive = true
06

Типові питання на співбесіді

Що таке intrinsicContentSize?

Природній розмір view на основі його контенту. UILabel — залежить від тексту і шрифту. UIButton — від тексту + padding. UIImageView — від розміру зображення. Якщо view має intrinsicContentSize — не обов'язково задавати width і height constraints.

Як анімувати зміну constraint?
// 1. Змінюємо constant
myConstraint.constant = 200
// 2. Викликаємо layoutIfNeeded всередині animate
UIView.animate(withDuration: 0.3) {
    self.view.layoutIfNeeded()
}
Frame vs Auto Layout — коли що?

Frame — точні координати, швидше але не адаптивне. Використовують для кастомних анімацій або колекцій з кастомним layout. Auto Layout — адаптивне, підходить для більшості UI. На співбесіді: для стандартного UI — Auto Layout, для складного кастомного — frame або обидва разом.

Що таке Ambiguous Layout?

Недостатньо constraints — система не може однозначно визначити розмір або позицію view. Xcode показує попередження. Дебажити: view.hasAmbiguousLayout або View Debugger.
