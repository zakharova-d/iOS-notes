01

Потоки — основи

Main thread vs Background thread

Main thread — єдиний потік де можна оновлювати UI. Background thread — для важкої роботи: мережа, парсинг, запити до БД.

Main thread — як касир в магазині: він обслуговує покупців (UI). Якщо змусити його ще й розвантажувати товар (мережевий запит) — черга стоїть, додаток зависає.
Що буде якщо оновити UI з background? ❓ часто питають

Undefined behavior — краш або непередбачувана поведінка. Xcode покаже попередження "UI API called from background thread".

// Неправильно
URLSession.shared.dataTask(with: url) { data, _, _ in
    self.label.text = "готово"  // ❌ background thread!
}

// Правильно
DispatchQueue.main.async {
    self.label.text = "готово"  // ✓ main thread
}
02

GCD — Grand Central Dispatch

DispatchQueue — черга завдань

GCD — старий але все ще актуальний спосіб керувати потоками. Ти кидаєш завдання в чергу, система вирішує на якому потоці виконати.

main — для UI global() — фонова робота custom — власна черга
async vs sync ❓ питають

async — не чекає виконання, йде далі.
sync — блокує поточний потік до завершення.

DispatchQueue.global().async {
    // виконується паралельно
}
// sync на main → deadlock!
QoS — пріоритет

Quality of Service — пріоритет черги.

.userInteractive — UI анімації .userInitiated — дія юзера .utility — довгі операції .background — синхронізація
serial vs concurrent ❓ часто питають

Serial — завдання виконуються одне за одним. Concurrent — паралельно.

// Serial — власна черга (за замовчуванням serial)
let serial = DispatchQueue(label: "com.app.serial")

// Concurrent
let concurrent = DispatchQueue(label: "com.app.concurrent",
                               attributes: .concurrent)
Serial — одна каса в магазині, concurrent — кілька кас паралельно
03

async / await — сучасна конкурентність

Як працює async/await під капотом ❓ питають

async функція може бути призупинена (suspend) не блокуючи потік. Потік звільняється і може виконувати інші завдання. Коли результат готовий — функція відновлюється (resume).

Як офіціант: прийняв замовлення → пішов до інших столиків → повернувся коли страва готова. Він не стоїть і не чекає біля кухні.
MainActor — заміна DispatchQueue.main
// Старий спосіб
DispatchQueue.main.async { self.updateUI() }

// Новий спосіб
await MainActor.run { self.updateUI() }

// Або помітити весь клас
@MainActor
class MyViewModel: ObservableObject {
    // всі методи автоматично на main thread
}
withCheckedContinuation — міст між GCD і async

Якщо є старий код із completion handler — можна обгорнути в async функцію.

func fetchData() async throws -> Data {
    try await withCheckedThrowingContinuation { continuation in
        oldAPIWithCompletion { data, error in
            if let error { continuation.resume(throwing: error) }
            else if let data { continuation.resume(returning: data) }
        }
    }
}
04

Actor — захист від data race

Що таке data race і actor ❓ питають

Data race — два потоки одночасно читають/пишуть одні дані → непередбачуваний результат. Actor — як клас, але гарантує що до його стану звертається лише один потік одночасно.

actor Counter {
    private var value = 0

    func increment() { value += 1 }
    func get() -> Int { value }
}

let counter = Counter()
await counter.increment()  // await бо actor може бути зайнятий
Actor — як банківська каса з одним вікном: черга є, але плутанини з грошима немає
nonisolated

Якщо метод не торкається стану actor — можна позначити nonisolated, тоді await не потрібен.

actor MyActor {
    nonisolated func greet() -> String { "Hello" }
}
05

Task — одиниця async роботи

Task і TaskGroup
// Один Task
Task {
    let data = try await fetchData()
}

// Паралельні Tasks — withTaskGroup
let results = try await withThrowingTaskGroup(of: Post.self) { group in
    for id in [1, 2, 3] {
        group.addTask { try await fetchPost(id: id) }
    }
    return try await group.reduce(into: []) { $0.append($1) }
}
withTaskGroup — як відправити кількох кур'єрів одночасно і чекати поки всі повернуться
async let — паралельне виконання ❓ питають
// Послідовно — повільно (чекає кожен)
let user  = try await fetchUser()
let posts = try await fetchPosts()

// Паралельно — швидко
async let user  = fetchUser()
async let posts = fetchPosts()
let (u, p) = try await (user, posts)
06

Типові питання на співбесіді

GCD vs async/await — коли що?

async/await — для нового коду, читабельніше, безпечніше. GCD — для старого коду або специфічних задач (DispatchGroup, Semaphore, бар'єри для concurrent черг). На нових проєктах — async/await.

Що таке deadlock?

Deadlock — два потоки чекають один одного і обидва заблоковані назавжди. Класичний приклад: sync на main queue з main queue.

DispatchQueue.main.sync {  // ❌ deadlock якщо вже на main
    doSomething()
}
Чим Task відрізняється від Thread?

Thread — системний потік, дорогий ресурс. Task — легковагова одиниця роботи в Swift Concurrency. Багато Tasks можуть виконуватись на невеликій кількості потоків — система сама керує.
